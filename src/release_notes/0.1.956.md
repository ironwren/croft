feature: closing tags are written for you. Typing the `>` of an opening tag in HTML, XML, or JSX in `.js`, `.jsx` and `.tsx` files inserts the matching `</tag>` and leaves the caret between the pair. Void elements such as `<br>` and `<img>`, closing tags and self-closing tags are left alone, and one undo takes the whole thing back. In script files a `<` inside a string or comment never closes.
