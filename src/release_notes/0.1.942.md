fix: when a PDF fails to render, you now get the whole error rather than its first line. On a busy machine croft could stop reading the renderer's complaint before it had finished writing it, and poppler puts the specific cause after a generic opening line — so the half you needed was the half that went missing, with nothing to say anything had been cut off.
fix: Go to Definition works again on Python projects. A language server that advertises whole-project diagnostics and then never answers the request — `ty` does exactly this — held the connection to itself open while it waited, and every later request queued behind it. F12 and Ctrl+click did nothing at all, with no error to show for it. The wait is now bounded and no longer blocks anything else, so navigation, hover and completion keep working whatever the diagnostics do.
