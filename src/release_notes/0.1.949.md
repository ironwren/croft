feature: Emmet abbreviation expansion. `Cmd+Opt+Shift+E` (or "Emmet: Expand Abbreviation" in the command palette) turns the abbreviation left of the cursor into the markup it stands for, so `nav.menu>ul>li.item$*3>a[href=#]{Link $}` becomes a whole nav block in one keystroke. Supports nesting (`>`), siblings (`+`), grouping (`(...)`), repetition (`*3`), numbering (`$`, `$$$` to zero-pad), ids, classes, attributes and `{text}`, with implicit tag names inside lists and tables (`ul>.item` gives `li.item`). The expansion is indented with the buffer's own indent style and inherits the abbreviation's leading whitespace, and the caret lands inside the first empty element. Runs in HTML, XML and JSX buffers only, and leaves prose alone.
