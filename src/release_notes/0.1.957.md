feature: `.editorconfig` files are read and applied. A project that states its indentation, line endings and whitespace rules now gets them: `indent_style`, `indent_size`/`tab_width` and `end_of_line` take effect when a file opens, and `trim_trailing_whitespace` and `insert_final_newline` are applied on save. Nearest file wins, `root = true` stops the search, and the status-bar indent picker still overrides everything.
